# 家谱校年与无年份工坊簿册断代

纯 Python 3.11 标准库实现，无第三方依赖。年份为小整数，岁数一律取两个年份
之差（如书写年 130、出生年 100 ⇒ 时年 30），全程不使用公历。

## 文件

| 文件 | 作用 |
| --- | --- |
| `chronicle.py` | 业务程序：家谱校年、簿册编目，共用一个命令行入口 |
| `crosscheck.py` | 独立朴素暴力实现，交叉核验 `chronicle.py` 的全部结论 |
| `case.json` | 题面样例（2 人、1 条亲缘记载、2 叶、两条 changes） |
| `case2.json` | 补充样例：3 叶，且唯一一条亲缘记载有两位候选家长 |
| `reports/` | 复跑后生成的每阶段中文报告（.txt）与机器可读见证（.json） |

## 数据格式（case.json）

```jsonc
{
  "family": {
    "years": {"甲": [100, 104]},          // 每人非空、离散的候选出生年
    "links": [{
      "id": "K",
      "parents": ["甲"],                   // 候选家长（可两位，各记载独立择一）
      "child": "乙",
      "age": [25, 25]                      // 家长生育当年年龄的闭区间
    }]
  },
  "book": {
    "years": [125, 140],                   // 馆方给定的闭年份范围
    "leaves": [{
      "id": "F",
      "mentions": [{"person": "甲", "age": [30, 30]}]  // 同叶多人共用同一书写年
    }],
    "gaps": [[0, 0]]                       // 相邻叶书写年差的非负闭区间，叶数-1 条
  },
  "changes": [
    {"path": "family.years.甲", "value": [104]},   // 点路径整体替换，读入即重新校年
    {"path": "book.gaps", "value": [[4, 4]]}       // 仍在原始家谱上改接缝
  ]
}
```

## 判定口径

- **家谱完整解释**：为每个人择一个出生年、每条记载择一位家长，全部生育年龄
  闭区间同时成立，且「家长→孩子」方向在跨全部记载的联合择定下不成环。
  同一人无论出现在哪条记载，出生年唯一；各条记载的家长独立择定。
- **单叶可行（边际）年份**：只看该叶年龄闭区间、在任一套可共存家谱上能落的
  全部书写年，不要求接缝可过。
- **两叶联合可行年对**：必须同属一条贯穿整册的年序（同时过全部接缝），并附
  该年序的完整见证；不是两叶边际年的笛卡尔积。
- **每个可行结论都带见证**：一套全体出生年、各记载择定的家长、每叶书写年。
- **两种无解严格区分**：`family_contradiction`（家谱本身无完整解释）与
  `book_impossible`（家谱有解，但接缝/范围使此册编不成）。

## 命令

```bash
# 题面要求的四阶段复跑（原始家谱、原始簿册、家谱变更、簿册接缝变更），
# 并把每阶段 .txt 与 .json 落到 reports/case1/
python3 chronicle.py run-case case.json --out reports/case1

# 三叶双候选家长样例
python3 chronicle.py run-case case2.json --out reports/case2

# 家谱查询（可用 --change N 应用 changes 的第 N 条，0 起）
python3 chronicle.py family case.json --person 甲
python3 chronicle.py family case2.json --pair 甲 丙
python3 chronicle.py family case.json --change 0 --json

# 簿册查询（叶下标 0 起；--leaves I J 只看指定两叶的联合年对）
python3 chronicle.py book case.json
python3 chronicle.py book case2.json --leaves 0 2
python3 chronicle.py book case.json --change 1 --json

# 独立暴力交叉校验（另起一套不共享代码的实现，全量比对解、边际、联合年对与见证）
python3 crosscheck.py case.json case2.json
```

## 样例预期（case.json）

1. 原始家谱：甲∈{100,104}、乙∈{125,129}，记载 K 要求甲 25 岁生乙，
   完整解释只有 (甲=100,乙=125) 与 (甲=104,乙=129) 两套。
2. 原始簿册：接缝 [0,0] 要求两叶同年。F（甲时年 30）与 G（乙时年 5）
   只能同时为 130 或同时为 134；联合年对仅 (130,130)、(134,134)。
3. 应用 changes[0]（甲候选年改为 [104]）重新校年：只剩 (甲=104,乙=129)，
   两叶都只剩 134。
4. 回到原始家谱，仅应用 changes[1]（接缝改为 [4,4]）：两叶各自的可行年份
   仍是 130、134，但没有任何年对满足「晚四年」，判定
   `book_impossible`（家谱有解但此册编不成），并给出接缝诊断。

## 补充样例（case2.json）

三人（甲、乙、丙）、三叶（F/G/H），记载 L1 的候选家长为甲、乙两人。
原始接缝 [0,15] 下可编成，见证中可同时看到 L1 择甲与择乙的完整解释；
changes[0] 把丙的候选年收窄为 [120] 后重新校年；changes[1] 把两条接缝
都改为 [0,0] 时，F、G 的候选年不交，判 `book_impossible`。

## 规模与方法

题目上限：至多 5 人、每人 3 个候选年、3 条记载每条 2 位候选、4 叶、
范围 20 个整数年。家谱端枚举出生年笛卡尔积并逐记载过滤家长、枚举择定做
三色无环检测；簿册端先按出生年向量去重家谱解，再对每套解做接缝剪枝 DFS，
收集每个边际年与每对联合年对的首条贯穿见证，目标见证集齐即停。
馆员反复试合接缝时，家谱解只算一次并在同一进程内复用。
